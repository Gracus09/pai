# IntentFlow

This directory contains AI chat history captured by the IntentFlow VS Code extension.

## Structure

- `history/` - Markdown exports of AI conversations (git-friendly, committable)
- `store/` - Structured JSON data for search/analysis (gitignored)
- `backups/` - Backups of overwritten rule files (gitignored)
- `metrics/` - Usage metrics and analytics data (gitignored)

## Why?

IntentFlow captures the reasoning behind your code decisions made during AI conversations.
This helps team members understand why choices were made, and helps AI assistants
learn from your project's history.
